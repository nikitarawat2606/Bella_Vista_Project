# 🍝 Bella Vista — Authentic Italian Restaurant Website

A responsive Italian fine-dining landing page built with **HTML5, Modern CSS3 (Grid & Flexbox), and Vanilla JavaScript**.

## ✨ Key Features & Trends (2026 Edition)
- **Glassmorphism Navbar**: Frosted blur header effect with CSS `backdrop-filter`.
- **Interactive Menu Filter**: Dynamic category switching (Starters, Mains, Desserts, Drinks) using JavaScript.
- **Reservation System**: Interactive date-locking reservation form with instant Toast notifications.
- **Mobile Responsive**: Custom side-drawer mobile navigation.
- **Typography & Aesthetics**: Google Fonts (`Playfair Display` + `Plus Jakarta Sans`) & FontAwesome icons.

## 🛠️ Tech Stack
- **HTML5** (Semantic structure)
- **CSS3** (Custom properties/variables, Grid, Flexbox, Keyframe animations)
- **JavaScript ES6+** (DOM Manipulation & Event Listeners)
