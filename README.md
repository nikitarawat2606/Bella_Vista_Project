# Bella Vista Restaurant Website

A responsive, static website for **Bella Vista – Authentic Italian Cuisine**, built with HTML and CSS.  
This project showcases a restaurant landing page with sections for menu, about, reservations, and contact details.

---

## 📂 Project Structure


---

## 🚀 Features

- **Header & Navigation**
  - Logo and tagline
  - Navigation links: Home, Menu, About Us, Contact Us

- **Hero Section**
  - Welcome message
  - Call-to-action buttons: *View Menu* and *Make Reservations*

- **Menu Section**
  - Categories (e.g., Appetizers)
  - Example dishes with descriptions and prices

- **About Section**
  - Restaurant story and background
  - Image of restaurant interior

- **Contact Section**
  - Address, phone, and email
  - Reservation form with fields:
    - Name, Email, Phone
    - Date, Time, Guests
    - Special requests

- **Footer**
  - Quick links
  - Opening hours
  - Social media links
  - Copyright

---

## 🎨 Design Notes

- **Typography & Layout:** Clean, semantic HTML with consistent headings and spacing.
- **Responsiveness:** Designed to adapt across desktop, tablet, and mobile.
- **Accessibility:** Includes labels for form inputs and alt text for images.
- **Known Issues / Deviations:**
  - Some placeholder text and images are used.
  - Opening hours contain minor typos (e.g., "Suunsay" → "Sunday") – can be corrected in future iterations.
